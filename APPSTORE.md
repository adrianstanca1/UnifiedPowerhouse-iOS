## App Description

### Full Description
Unified Powerhouse puts your entire system infrastructure in your pocket. Monitor agents, manage processes, and control your unified system in real-time.

**Key Features:**

🔴 **Real-Time Monitoring**
- Live agent status with animated indicators
- System metrics (CPU, Memory, Disk, Load)
- PM2 process monitoring
- Docker container tracking

💬 **Interactive Control**
- Command terminal for remote execution
- Chat console for agent messaging
- Quick action buttons for common tasks
- WebSocket connectivity for instant updates

🔒 **Secure Access**
- JWT authentication
- Face ID / Touch ID biometric login
- SSL/TLS encrypted connections

📊 **Rich Dashboard**
- Dark theme optimized for professional use
- Historical charts for metrics
- Process health indicators
- Log streaming

🚀 **Advanced Features**
- iOS widgets for quick status checks
- Siri Shortcuts for voice commands
- Push notifications for critical alerts
- Offline mode with local caching

**Perfect for:**
- System administrators
- DevOps engineers
- Platform architects
- Infrastructure teams

**Backend Required:**
Requires Unified Powerhouse dashboard server (https://dashboard.cortexbuildpro.com)
